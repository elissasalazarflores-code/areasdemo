# Demo · Cine Areas × TaquillApp para Empresas

Demo de una sola página que presenta el beneficio corporativo de cine para colaboradores de Areas.

**Uso offline:** abre `index.html` con doble clic en cualquier navegador. Es un archivo autocontenido (logo, estilos y scripts incluidos); no necesita internet ni servidor.

Incluye: hero con mensaje principal, beneficios, cómo funciona, catálogo filtrable (Cinépolis, Cinemex, combos), carrito y compra simulada con folios de ejemplo, instrucciones de canje, calculadora de ahorro, sección para RH y preguntas frecuentes.

**Editar precios:** en `index.html`, busca `const PRODUCTS=[`. `price` es el precio Areas (catálogo TaquillApp) y `ref` el precio de referencia en taquilla (ilustrativo); el % de descuento se calcula solo.

`assets/areas-logo.jpg` es el logo recortado (ya va incrustado en el HTML).
